# Atoll source review: network, credentials and data flows

Reviewed source snapshot: `Ebullioscopic/Atoll` at `b8d86a2d8118d905ffa3e2c912adc736683741bb`.

This is a static review of source text, not a running-app traffic capture or a certification that distributed binaries match this source. No app, repository script, build, installer, package or helper was executed. External dependencies, Apple frameworks and embedded framework binaries were not audited internally. Line references below refer to this pinned snapshot. No user credentials were accessed.

## Main findings

### 1. LocalSend permits unauthenticated TLS trust and plaintext fallback

**Confirmed code behavior; high priority before reusing this component.** `LocalSendTLSDelegate` accepts any supplied server trust with `.useCredential`, with no certificate validation or fingerprint comparison in the delegate. Both probing and transfer sessions use this delegate. `candidateBaseURLs` includes the advertised scheme and its HTTP/HTTPS alternative; connection and TLS failures are among the errors that allow retry. As a result, an HTTPS-advertised peer can be retried over HTTP, including file metadata and file bytes. HTTPS here provides encryption without verified peer identity; the HTTP fallback provides no transport encryption. This is not evidence that a transfer has been intercepted, and discovery/transfer is LAN functionality rather than a demonstrated Internet exfiltration route.

Sources: [TLS delegate and sessions, LocalSendService.swift:1053–1064](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L1053-L1064), [scheme fallback:1024–1044](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L1024-L1044), [metadata preparation:877–929](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L877-L929), [file upload:976–1013](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L976-L1013).

Recommended original-app design: leave LAN transfer off unless requested; use explicit peer selection and verified pairing/fingerprints; require encryption and never silently downgrade a credential-bearing or file-bearing transfer.

### 2. AI API keys and Spotify Canvas credentials remain in ordinary preferences

**Confirmed; medium priority.** The four Screen Assistant cloud keys are `Defaults.Key<String>` values. `ModelSelectionPanel.saveSettings` writes them to Defaults. Spotify's Canvas/web-player `sp_dc` cookie and cached access token are also stored in Defaults. These values are not protected by the Keychain APIs used elsewhere in the project. This is a local secret-storage weakness; it does not establish that the values are sent to unrelated servers or that the Mac is compromised.

Sources: [AI defaults, Constants.swift:1368–1378](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/models/Constants.swift#L1368-L1378), [settings persistence, ModelSelectionPanel.swift:324–335](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/ScreenAssistant/ModelSelectionPanel.swift#L324-L335), [Canvas cookie/token, SpotifyAuthManager.swift:96–118](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/SpotifyAuthManager.swift#L96-L118).

Positive distinction: Spotify **library** OAuth access/refresh tokens use `KeychainSpotifyTokenStore` and PKCE. Cider's token uses `CiderTokenStore`, including a migration that only clears the old preference after a successful Keychain write. New API keys also use Keychain. Do not describe all Spotify credentials as either secure or insecure: the two Spotify integrations differ.

Sources: [SpotifyTokenStore.swift:36–72](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/Spotify/SpotifyTokenStore.swift#L36-L72), [PKCE, SpotifyOAuthService.swift:70–109](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/Spotify/SpotifyOAuthService.swift#L70-L109), [CiderTokenStore.swift:31–48](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/MediaControllers/CiderTokenStore.swift#L31-L48), [NewAPIUsage.swift:37–83](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LLMUsage/NewAPIUsage.swift#L37-L83).

### 3. Screen Assistant writes user content into console output

**Confirmed; medium priority.** `sendMessage` prints the entire prompt. File-entry creation prints full file URLs; response parsers and `addAssistantMessage` print the first 100 characters of responses. These are direct `print` calls outside `#if DEBUG`. The central Logger defaults to no logging, but that setting filters `Logger.log` and the custom `NSLog`, not these direct prints. Actual persistence/exposure depends on how the app is launched and how stdout is collected; the source alone does not prove all these strings persist in macOS unified logging.

Sources: [prompt and attachment logs, ScreenAssistantManager.swift:365–375](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L365-L375), [file URL:100](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L100), [response example:867–878](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L867-L878), [assistant content:1190–1193](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L1190-L1193), [logging default, Constants.swift:987](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/models/Constants.swift#L987), [Logger filtering, Logger.swift:83–103 and 156–173](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/utils/Logger.swift#L83-L103).

Original app should never log prompt, clipboard, screenshot, attachment names/paths or tokens by default. Diagnostic export should be explicit and redact sensitive fields.

### 4. Some network features are enabled by default or start incidentally

**Confirmed privacy/control mismatch for an offline-first fork, not inherently malicious behavior.** Weather defaults on and launch prepares Location permission and forces refresh. If no permitted location is available, the provider falls back to a request to `wttr.in` without coordinates; the server can observe the request's source IP. Opening the shelf's `FileShareView` starts LocalSend discovery regardless of selected share provider. Discovery broadcasts the Mac's localized host name, device type/model and app bridge identifier on UDP multicast; a TCP register/info listener is created on port 53317. An 8-second announcement loop remains active; the reviewed class has no stop-discovery API.

Sources: [weather default, Constants.swift:1095–1108](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/models/Constants.swift#L1095-L1108), [startup, DynamicIslandApp.swift:1103–1108](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/DynamicIslandApp.swift#L1103-L1108), [no-location fallback, LockScreenWeatherManager.swift:603–626](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LockScreenWeatherManager.swift#L603-L626), [share view starts discovery, FileShareView.swift:51–56](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Views/FileShareView.swift#L51-L56), [discovery loops, LocalSendService.swift:87–129](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L87-L129), [announcement payload:600–616](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L600-L616), [listener:619–647](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L619-L647).

### 5. App Transport Security is globally relaxed

**Confirmed hardening gap.** Info.plist sets `NSAllowsArbitraryLoads = true`. Known cloud API literals use HTTPS, but a global exception also permits HTTP for configurable endpoints, remote animations and arbitrary HTTP artwork. New API explicitly accepts non-loopback HTTP base URLs and sends its bearer key in the Authorization header. Screen Assistant's configurable “local” endpoint is not restricted to loopback or to HTTPS, so its name is not a network boundary. The default Ollama address is loopback; this is not a claim that default local mode sends outside the Mac.

Sources: [Info.plist:5–9](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/Info.plist#L5-L9), [New API schemes, NewAPIUsage.swift:162–176](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LLMUsage/NewAPIUsage.swift#L162-L176), [bearer request:256–262](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LLMUsage/NewAPIUsage.swift#L256-L262), [local AI URL construction, ScreenAssistantManager.swift:508–524](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L508-L524).

### 6. Extension web content's navigation filter is not a complete request firewall

**Confirmed configuration gap with impact inferred from the API boundary; not dynamically exploited.** The view loads extension-provided HTML into a default `WKWebViewConfiguration`. `WKNavigationDelegate` decides navigation actions based on `allowRemoteRequests` / `allowLocalhostRequests`, but there is no content-rule list, injected restrictive CSP or custom URL scheme handler in this view. Navigation policy is not a general resource-request policy; remote images, scripts and script-initiated requests need separate enforcement. The default WebKit data store is also not explicitly changed to nonpersistent here, unlike Spotify login's explicit `.nonPersistent()` store. This does not show a particular extension stealing data; it means “remote navigation blocked” should not be represented as “all remote network disabled.”

Sources: [web view setup, ExtensionLockScreenWidgetView.swift:297–307](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Extensions/ExtensionLockScreenWidgetView.swift#L297-L307), [navigation checks:357–395](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Extensions/ExtensionLockScreenWidgetView.swift#L357-L395), [Spotify nonpersistent comparison, SpotifyLoginSheet.swift:102–105](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Settings/SpotifyLoginSheet.swift#L102-L105).

For an original local app, avoid arbitrary HTML extensions initially. If introduced, deny resource networking by policy, default JavaScript off, use an ephemeral data store and authenticate the extension independently of HTML permissions.

API reference supporting that distinction: Apple's [WKNavigationDelegate documentation](https://developer.apple.com/documentation/webkit/wknavigationdelegate) describes navigation changes/main-frame transitions; [WKContentRuleListStore](https://developer.apple.com/documentation/webkit/wkcontentruleliststore) separately provides resource-content filtering. The WebKit team's [content blocker explanation](https://webkit.org/blog/3476/content-blockers-first-look/) describes rules evaluated for resource requests in the network subsystem. The clipboard's HTML-to-NSAttributedString import is another resource-loading surface worth testing, but it is not counted here as a confirmed outbound request without runtime verification.

## Network and memory optimization opportunities

1. **Offline-first switches:** central per-feature network policy; weather, remote metadata, animated assets, pricing refresh, LAN discovery and updates should each have a switch and clear explanation. Disabling the feature must cancel network tasks/listeners and timers. Today weather defaults on and LocalSend starts from view appearance.
2. **Stop LocalSend when unused:** cancel multicast/TCP listeners and 8-second announcements when share UI closes or feature is disabled. Keep subnet probing an explicit fallback; current refresh can scan hosts 1–254 with concurrency 50 after multicast/targeted failure. [LocalSendService.swift:258–283](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L258-L283).
3. **Stream files instead of loading a transfer batch into RAM:** LocalSend builds a `[TransferFile]` with full `Data(contentsOf:)` for each selected file, then uploads them sequentially. Large file batches can consume the sum of file sizes. Prefer file-backed upload tasks and bounded concurrency. [LocalSendService.swift:829–865](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L829-L865), [uploads:523–547](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/components/Shelf/Services/LocalSendService.swift#L523-L547).
4. **Bound assistant attachments:** Gemini reads whole files, base64-encodes and serializes a pretty-printed JSON body; there is no size cap in the reviewed attachment path. Limit count/pixels/bytes before encoding, downsample screenshots, do disk reads off the UI thread, use compact JSON and offer clear unsupported/oversize errors. This reduces memory copies and payload cost. [ScreenAssistantManager.swift:684–693](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L684-L693), [file loading:1012–1042](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/ScreenAssistantManager.swift#L1012-L1042).
5. **Bound music metadata caches and deduplicate services:** explicitness caches are capped at 300 entries, but Spotify artist/Canvas dictionaries only have TTL checks on lookup, with no global eviction in those actors. Add a capacity and prune expired keys. Avoid two separate public Spotify embed downloads for artist and explicitness metadata for one track. [artist cache:421–459](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/MediaControllers/SpotifyController.swift#L421-L459), [Canvas cache:596–612](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/MediaControllers/SpotifyController.swift#L596-L612).
6. **Single-flight weather refresh:** initialization schedules a forced refresh and app startup also schedules a forced refresh; refresh has a freshness cache but no in-flight guard and both forced paths bypass it. Coalesce callers into one shared task; prevent redundant initial location/network work. [manager init:36–42](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LockScreenWeatherManager.swift#L36-L42), [app startup:1103–1108](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/DynamicIslandApp.swift#L1103-L1108), [refresh:91–121](https://github.com/Ebullioscopic/Atoll/blob/b8d86a2d8118d905ffa3e2c912adc736683741bb/DynamicIsland/managers/LockScreenWeatherManager.swift#L91-L121).
7. **Incremental usage parsing:** Antigravity walks recent conversations/steps each refresh. Cache processed ids/timestamps rather than repeatedly reading whole week trajectories, and request only usage metadata if supported. This is a local performance/privacy minimization improvement, not proof the responses were sent externally.
8. **Keep useful safeguards:** preserve lyrics' disabled guard, cancellation and cache; image-session cookie suppression and cache bounds; OAuth refresh single-flight; MusicKit auth backoff; ephemeral sessions for quotas/weather. Add measurable request count/bytes and memory/idle CPU tests to catch regressions.

## Remaining verification required before trusting a build

- Compare buildable source/release binary provenance and inspect every linked framework/dependency separately.
- Run a controlled traffic capture with all optional features off, then enable each integration one at a time. Confirm first-run update behavior and whether setting changes cancel in-flight work.
- Test LocalSend pairing, malicious/duplicate peer metadata, TLS failure and downgrade behavior with synthetic files only.
- Test extension webview remote subresources/network permissions in a minimal harness before claiming isolation.
- Test that diagnostics remain content-free and that API secrets are absent from preference files, logs, URLs in exported diagnostics and crash attachments.
- Confirm screenshot shelf files never leave the Mac except through deliberate user sharing; the assistant's cloud Send is a separate user-visible action.
